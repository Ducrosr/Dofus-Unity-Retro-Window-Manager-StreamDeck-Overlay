Le principe

Votre clavier suffit.

Ouvrez vos clients, choisissez l’ordre de vos personnages, puis jouez. Aucun matériel supplémentaire n’est requis.

01

Détectez vos fenêtres

Le gestionnaire reconnaît les clients Unity ou Retro déjà ouverts.

02

Organisez votre équipe

Classez les personnages, ajoutez des alias et sauvegardez un profil.

03

Changez de fenêtre

Utilisez F5/F6, l’overlay ou, si vous le souhaitez, votre Stream Deck.

Conçu autour de votre façon de jouer.

⌨

Raccourcis globaux

Passez instantanément d’un personnage à l’autre, même lorsque le gestionnaire est réduit.

◎

Overlay en jeu

Gardez l’ordre, le personnage actif et les alertes visibles dans un affichage personnalisable.

▦

▤

Ajoutez des touches dynamiques si vous possédez le matériel. L’application reste complète sans lui.

Questions fréquentes

Avant de commencer.

Faut-il un Stream Deck ?

Non. Les raccourcis clavier globaux, l’overlay, le mode compact et toutes les fonctions de gestion sont disponibles sans Stream Deck. Le plugin est optionnel.

Quels jeux sont compatibles ?

Dofus Unity et Dofus Retro sous Windows 10 ou 11 en 64 bits.

L’application demande-t-elle mes identifiants Ankama ?

Jamais. Elle gère uniquement les fenêtres locales et ne lit ni la mémoire ni les paquets réseau de Dofus.

Où télécharger la version officielle ?

Uniquement dans les Releases du dépôt GitHub Ducrosr. Évitez les miroirs, messages privés et sites tiers.

Prêt à gagner en fluidité ?

Installez. Ordonnez. Jouez.

Commencez avec les raccourcis clavier. Ajoutez l’overlay ou Stream Deck seulement si cela vous est utile.
